### Video 1: Bucko Trades — Mechanical Candle Closure Signatures
* **Core Philosophy:** *Wicks do the lying (liquidity sweeps); bodies tell the truth (conviction).*
* **Primary Timeframes:** Daily, 6-Hour (Quarterly Theory sessions), 90-Minute.

Bucko categorizes every candlestick into one of **three mechanical closure signatures**:

```
1. REVERSAL SIGNATURE              2. CONTINUATION SIGNATURE           3. INSIDE CANDLE
      [Wick Above High]                     [Close Above High]                 [Inside Range]
            ▲                                      ▲ 
          ┌───┐                                  ┌───┐ 
   Prev   │   │ Body Closes               Prev   │   │ Body Closes       Prev   ┌─────┐
   High --┼───┼-- INSIDE Previous         High --│   │-- ABOVE Previous  High --│     │
          │   │   Range                          │   │   Range                  │     │ Current
          └───┘                                  └───┘                          │ ┌─┐ │ Stays
   Next Candle Prediction:                Next Candle Prediction:               │ └─┘ │ Inside
   REVERSE towards Candle Low             CONTINUE higher past High      Low  --└─────┘
```

#### 1. Reversal Candle Signature
* **Condition:** Candle $N$ takes out Candle $N-1$'s high (or low) with a wick, but **fails to close beyond it**. The body closes back *inside* Candle $N-1$'s range.
* **Next Candle ($N+1$) Expectation:** **Reversal**. The upcoming candle will expand in the opposite direction, with an initial target of Candle $N$'s opposite extreme (and often Candle $N-1$'s extreme).

#### 2. Continuation Candle Signature
* **Condition:** Candle $N$ takes out Candle $N-1$'s high (or low) and **its body closes firmly beyond that level**.
* **Next Candle ($N+1$) Expectation:** **Continuation**. The upcoming candle is expected to continue expanding in the same direction, taking out the high (or low) of Candle $N$.

#### 3. Inside Candle Signature
* **Condition:** Candle $N$'s entire range (high to low) remains within Candle $N-1$'s range.
* **Next Candle ($N+1$) Expectation:** **Consolidation / Pause**. Do not force a trade inside the range. Anticipate the eventual expansion to follow the direction of the **most recent impulse/closure signature**.

#### Practical Application (6-Hour Quarterly Sessions):
* Divide the 24-hour day into 4 six-hour candles:
  * Candle 1: Asia Session
  * Candle 2: London Session
  * Candle 3: New York AM Session
  * Candle 4: New York PM Session
* If London sweeps Asia's low and closes back inside (Reversal Signature), New York AM's candle has a high-probability bullish bias targeting London's high.

### Video 2: Novo Legacy — 3-Candle Session Framework & Market Objectives
* **Core Philosophy:** *The market only has two objectives: Sweep Liquidity and Fill Fair Value Gaps (FVGs).*
* **Primary Timeframe:** 4-Hour (HTF) synchronized with 5m/15m (LTF).

Novo explains that predicting the next candle is not chart-pattern guessing—it is understanding **market delivery cycles** and **clock timing**.

#### The 3-Candle Session Sequence on 4-Hour Timeframe:
Novo uses the UTC-4 timezone (or EST for US Futures):

| Candle | Time (UTC-4) | Time (EST / Futures) | Session Role | Function |
| :--- | :--- | :--- | :--- | :--- |
| **Candle 1** | **01:00** | **02:00** | Asia End / London Prep | Sets the initial range and liquidity boundaries |
| **Candle 2** | **05:00** | **06:00** | London Session | **Manipulation / Objective Phase:** Sweeps Candle 1 liquidity OR mitigates an HTF FVG/OB |
| **Candle 3** | **09:00** | **10:00** | **New York Open** | **The Trade Candle:** Expansion candle towards the opposing Draw on Liquidity (DOL) |

#### Candlestick Anatomy & AMD (Power of 3):
Every high-probability directional candle follows:
1. **Open**
2. **Manipulation (Wick):** Quick move against the true direction to engineer liquidity or tap an imbalance.
3. **Distribution (Body):** Strong directional displacement leaving behind imbalances.
4. **Close:** Closes near the extreme.

#### LTF Synchronization:
* When Candle 2 (London) shows a wick rejection off a key level on the 4H, the 5m/15m chart will display:
  * A **Turtle Soup** (false breakout / run on stops).
  * A **Change in State of Delivery (CISD)** / Market Structure Shift.
  * An **Inverse FVG** or newly formed order flow leg.
* Candle 3 (9:00 AM NY Open) then triggers clean trend continuation to the opposing high/low.

### Video 3: Sir Pickle — Respect vs. Disrespect of PD Arrays & "Inside the Wick"
* **Core Philosophy:** *A single higher-timeframe candlestick contains the complete lower-timeframe order flow story.*
* **Primary Timeframe:** Monthly / Weekly / Daily down to 1-Hour.

Sir Pickle answers the critical trader question: **"How do I know if this Fair Value Gap or Support/Resistance level will hold?"**

```
RESPECT CANDLE (Level Holds)              DISRESPECT CANDLE (Level Fails)
       [HTF PD Array / FVG]                      [HTF PD Array / FVG]
     ─────────────────────────                 ─────────────────────────
               │ Wick Rejection                           │
               ▼                                          │
            ┌─────┐                                    ┌─────┐
            │     │ Small Body                         │     │ Large Body Closes
            │     │ Closure Away                       │     │ Through the Zone
            └─────┘                                    │     │
                                                       └─────┘
     LTF Order Flow: FLIPPED                   LTF Order Flow: CONTINUES
     Next Candle: Follow-Through               Next Candle: Slices Further
```

#### 1. Respect Candles (Reversal & Hold)
* **Visual Signature:** A long wick testing the PD Array with a **small body closure** remaining outside/away from the level.
* **What is "Inside the Wick"?**
  * When a Monthly or Daily candle forms a long lower wick, zooming into the 1H/15m reveals that **bearish order flow died and bullish order flow took over**.
  * Lower-timeframe FVGs flipped from resistance to support (Inversion).
* **Next Candle Expectation:** **Follow-through expansion**. The open of the next candle briefly dips into an internal LTF FVG, then accelerates towards the Draw on Liquidity.

#### 2. Disrespect Candles (Blow-Through / Invalidation)
* **Visual Signature:** Strong candle body closing directly through the PD Array with little to no wick.
* **Underlying Logic:** Lower timeframe order flow never shifted. Institutional volume is seeking the *next* deeper pool of liquidity.
* **Next Candle Expectation:** Continued momentum in the breakout direction. Treat the broken PD Array as an Inverted FVG or breaker zone.

## 5. Algorithmic Implementation Guide (For ICT Sentinel AI)

If integrating this logic into automated scanners, backtesters, or indicator scripts (Python / Pine Script):

### 1. Data Structure Definitions
```python
def classify_candle_signature(prev_candle, curr_candle):
    """
    Classifies candle closure signature based on Bucko Trades logic.
    """
    took_high = curr_candle.high > prev_candle.high
    took_low = curr_candle.low < prev_candle.low
    closed_above_high = curr_candle.close > prev_candle.high
    closed_below_low = curr_candle.close < prev_candle.low

    # Reversal Signatures
    if took_high and not closed_above_high and curr_candle.close < prev_candle.high:
        return "BEARISH_REVERSAL_SIGNATURE"
    if took_low and not closed_below_low and curr_candle.close > prev_candle.low:
        return "BULLISH_REVERSAL_SIGNATURE"

    # Continuation Signatures
    if took_high and closed_above_high:
        return "BULLISH_CONTINUATION_SIGNATURE"
    if took_low and closed_below_low:
        return "BEARISH_CONTINUATION_SIGNATURE"

    # Inside Candle
    if not took_high and not took_low:
        return "INSIDE_CANDLE"

    return "NEUTRAL_EXPANSION"
```

### 3. PD Array Respect Filter
```python
def evaluate_pd_array_reaction(pd_array, candle):
    """
    Evaluates Sir Pickle's Respect vs Disrespect criteria.
    """
    # Did candle pierce the array?
    if candle.low <= pd_array.top and candle.high >= pd_array.bottom:
        # Check body closure
        body_top = max(candle.open, candle.close)
        body_bottom = min(candle.open, candle.close)
        
        # Bullish respect: wicks into/below array, but body closes above
        if candle.low < pd_array.bottom and body_bottom > pd_array.bottom:
            return "RESPECT_BULLISH"
        # Disrespect: body closes entirely through
        if candle.close < pd_array.bottom:
            return "DISRESPECT_BEARISH"
            
    return "NO_REACTION"
```

## 6. Practical Rules of Thumb & Risk Filters

1. **Never Trade the Inside Candle blindly:** Wait for the breakout candle to establish a continuation or reversal signature before committing.
2. **Body Over Wick:** If a candle takes liquidity by 1 pip but closes 30 pips past the level with a fat candle body, it is **NOT** a reversal. That is institutional displacement (continuation).
3. **Context Trumps Pure Candle Geometry:** A reversal candle that prints in the middle of nowhere without tapping an FVG, Order Block, or Major Swing Liquidity has a much lower win rate. High probability occurs when **Sir Pickle's Respect Level** matches **Bucko's Reversal Signature** during **Novo's London/NY Session**.
